### 3. Antigravity CLI 1.4.x: hook chặn prompt nhạy cảm, stream ít ghi hơn khoảng 70% qua SSH, import plugin từ Claude Code
- 🛑 Bản 1.4.11 cho `PreInvocation` hook trả `"terminate"` để dừng lượt trước khi gọi model (ví dụ chặn prompt chứa dữ liệu nhạy cảm), và hiển thị `errorMessage` cho người dùng mà không gửi cho model. Chạy `-p` thì thoát với mã khác 0
- 🧾 Output JSON/stream-json có thêm trường `finished_reason` (`print_timeout`, `interrupted`, `error`) để script phân biệt câu trả lời bị cắt với câu trả lời đầy đủ
- ⚡ Streaming ghi ít hơn khoảng 70% byte ra terminal nên mượt hơn qua SSH chậm; CLI trả lại khoảng 100 MB bộ nhớ thừa sau khởi động 15 giây
- 🔌 `agy plugin import claude` giờ đọc đúng danh sách plugin cài từ marketplace của Claude Code, giữ cả remote MCP server. Sau khi đăng nhập Google Cloud có thể chọn gói Gemini subscription hoặc Pay As You Go
- 🔗 [Nguồn](https://github.com/google-antigravity/antigravity-cli/blob/main/CHANGELOG.md)

### 6. OpenAI công bố "Scaling Git at OpenAI": hệ thống Pando dùng `packfile-uri` để chịu khối lượng code tăng nhanh
- 🗄️ Theo trích dẫn trên Hacker News, hệ thống Pando của OpenAI dùng riêng tính năng `packfile-uri` của giao thức Git (server trả link tải các pack riêng), và OpenAI đã đóng góp một số cải tiến cho tính năng này
- 📚 Một người đếm đây là bài lớn thứ năm về chủ đề scale source control, sau Cursor, GitHub (hai bài) và Anthropic, cho thấy khối lượng code do agent sinh ra đang đẩy hạ tầng Git tới giới hạn
- 🧐 Phản ứng khác nhau: có người khen bài viết kỹ thuật, ít hype, đầy số liệu và biểu đồ; người khác chê thiếu benchmark (số push mỗi giây, số người push đồng thời) và thắc mắc khối lượng code khổng lồ ấy thực sự làm gì
- 🛠️ Với dev: nếu monorepo của team đang chậm dần khi agent tạo nhiều commit, đáng đọc bài này để tham khảo hướng tách pack
