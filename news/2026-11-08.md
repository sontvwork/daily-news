# Daily News 08/11/2026

### 1. GitHub dựng lại kho lưu trữ Git cho thời agent: thử nghiệm 5.000 agent cùng ghi vào một repo, 7.200 lượt push mỗi giây
- 🏗️ GitHub công bố kiến trúc lưu trữ Git mới, qua bài kỹ thuật của hai kỹ sư GitHub. Theo tài khoản chính thức, thử nghiệm nội bộ cho thấy 5.000 agent chạy đồng thời trên một repo, đạt 7.200 push/giây mà độ trễ đọc vẫn thấp
- ☁️ Đã chuyển bản sao của 99,99999% repo sang Azure; phần còn lại sẽ chuyển bằng cơ chế quorum theo từng reference, và object storage giúp phần đọc scale độc lập với phần ghi
- 💬 Trên Hacker News có người nhận xét giống Continuity của Cursor nhưng thông lượng ghi cao hơn cả bậc; người khác chỉ ra đây chủ yếu giải bài toán scale dọc trong một repo chứ chưa chữa ngay các sự cố gần đây (có dev kể tuần này gặp nhiều lỗi 500 khi push)
- 🛠️ Với dev: nút thắt của agentic coding đang chuyển từ model sang hạ tầng Git. Nếu chạy nhiều agent song song trên cùng repo thì đây là tín hiệu tốt về giới hạn push sắp tới
- 🔗 [Nguồn](https://github.blog/engineering/architecture-optimization/inside-githubs-new-git-storage-architecture/)

### 2. Claude Code "Don't Ask Again" bị Apiiro nêu có thể lộ mật khẩu trong 1.122 file công khai trên GitHub
- 🔐 Apiiro quét các repo công khai và tìm thấy 1.122 file có mật khẩu/khoá nằm trong lệnh đã được duyệt bằng "Don't Ask Again" của Claude Code
- 🧾 Nhiều người trên Hacker News chỉ ra tiêu đề gây hiểu nhầm: bấm "Don't Ask Again" tự nó không làm lộ gì. Lộ khi dev commit thư mục `.claude/` cùng `settings.local.json`, trong đó lệnh đã duyệt chứa sẵn secret, rồi public repo
- 🧑‍💻 Boris của team Claude Code cho biết Claude Code trước giờ không tự lọc secret, hãng đang tìm cách ngăn. Ông nhắc `settings.local.json` chỉ để dùng cục bộ và Claude tự thêm vào gitignore khi tạo file
- 🛠️ Với dev: kiểm tra repo xem đã gitignore `.claude/settings.local.json` chưa. Một người đề xuất giữ credential trong trình quản lý mật khẩu (như 1Password) và để agent gọi qua CLI, mỗi lần cần thì xác nhận bằng vân tay thay vì dán secret vào lệnh
- 🔗 [Nguồn](https://apiiro.com/blog/coding-agents-leaking-secrets-github-dont-ask-again)

### 3. GitHub Copilot app có Projects (public preview): giao mục tiêu, Copilot chạy nhiều agent trên nhiều repo, kèm computer use
- 🗂️ Projects gom ngữ cảnh, agent và kết quả của một công việc vào một chỗ, kể cả việc trải qua nhiều repo hoặc không cần repo. Bạn mô tả mục tiêu, thêm repo, design mock, thread Slack hay ghi chú họp; Copilot chạy số agent cần thiết và trả về kết quả như pull request để review

- 🛠️ Với dev: hợp cho thay đổi xuyên nhiều repo mà trước đây phải điều phối tay. GitHub cũng vừa thêm Copilot vào Xcode và JetBrains Air trong tuần
