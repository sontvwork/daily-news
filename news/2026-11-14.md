### 1. Google Antigravity thêm Dynamic Workflows: agent tự viết script Python điều phối subagent, luồng chạy cố định thay vì "trôi" theo prompt
- 🧭 Gõ `/run-workflow`, agent sẽ viết một script Python để điều phối các subagent chạy song song hoặc tuần tự, với cơ chế bàn giao kết quả có cấu trúc giữa các bước
- 🎯 Điểm chính theo Antigravity: luồng điều khiển mang tính xác định (deterministic) thay vì "prompt drift", tức agent không tự lệch hướng giữa chừng như khi chỉ điều phối bằng prompt
- 🔍 Script được hiển thị để bạn review trước khi chạy, và có thể lưu lại để chạy lại đúng quy trình đó bất cứ lúc nào
- 🛠️ Với dev: hợp cho các quy trình lặp đi lặp lại (migrate, refactor hàng loạt, chạy kiểm tra nhiều bước), vì lưu được flow thay vì phải viết lại prompt mỗi lần. Tính năng đang được triển khai dần
- 🔗 [Nguồn](https://x.com/antigravity/status/2121327669534933025)

### 3. Claude Code 2.1.323: thêm Code Mode thử nghiệm, để Claude viết JavaScript gọi nhiều tool trong một bước
- 🧪 Code Mode là tính năng thử nghiệm, mặc định tắt: Claude viết JavaScript để gọi các tool của chính nó, gom nhiều lệnh gọi vào một bước. Bật bằng biến môi trường `CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1`, và phiên resume cũng cần cùng biến này
- 🏢 Tổ chức có thể tắt Code Mode cho toàn bộ thành viên, phù hợp với team cần kiểm soát
- 🔌 Plugin có thêm trường `engines["claude-code"]` trong `plugin.json`: plugin nằm ngoài dải phiên bản Claude Code khai báo sẽ không được cài, cập nhật hay nạp. Lệnh `claude plugin validate` giờ cũng kiểm tra kiểu cho module hook TypeScript của plugin
- 🔗 [Nguồn](https://github.com/anthropics/claude-code/releases/tag/v2.1.323)

### 5. Brave Search API nhận thanh toán cho agent qua giao thức x402: không cần tài khoản hay API key, $5 cho 1.000 lượt
- 💳 Agent gọi API, nhận về HTTP 402 Payment Required kèm giá và thông tin thanh toán, ký giao dịch USDC rồi gửi lại request kèm bằng chứng thanh toán. Brave tự vận hành facilitator, hiện nhận USDC trên mạng Base, các mạng và stablecoin khác sẽ có sau
- 💰 LLM Context (API cấp context tìm kiếm cho agent) và các endpoint web, news, image, video, local đều $0,005 mỗi request ($5 cho 1.000). Phí gas trên Base được Brave trả trong thời gian giới hạn
- 🛠️ Cách bắt đầu nhanh nhất: dùng Purl Wallet, ví CLI do Stripe phát triển, nạp USDC trên Base rồi cho agent truy vấn
- 💬 Trên Hacker News, nhiều người thấy giá khá đắt (một phiên ChatGPT thường có thể gọi 30 lượt tìm kiếm, tức khoảng $0,15). Một người đã triển khai x402 trên một site bị crawl nhiều nhưng chưa thấy giao dịch nào
- 🔗 [Nguồn](https://brave.com/blog/search-api-agentic-payments/)
