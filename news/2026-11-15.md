### 4. Cloudflare mở mã nguồn Kitesurf, trình duyệt cho AI agent chạy hoàn toàn trên Workers
- 🌐 Kitesurf mở trên GitHub theo giấy phép Apache 2.0. Nó phân tích HTML, áp CSS, chạy JavaScript của trang và render ảnh chụp màn hình mà không cần container trình duyệt, scale theo nhu cầu trên mạng Workers
- 🔌 Hỗ trợ Chrome DevTools Protocol nên nối thẳng với Puppeteer hoặc cho agent trỏ vào cổng CDP. Xây trên các package Rust biên dịch sang WebAssembly: Blitz (HTML/DOM/layout), Stylo (CSS), Boa (JavaScript, chỉ là phương án cuối)
- 🛠️ Chạy thử local: `git clone`, `pnpm install --frozen-lockfile`, `pnpm run dev` (lần build đầu biên dịch Rust nên khá lâu). Muốn tự triển khai lên tài khoản Cloudflare thì dùng `pnpm run deploy`, cần gói Workers Paid vì dùng Dynamic Workers
- 📉 Một bài đăng X trích số liệu: mỗi ảnh chụp dùng khoảng 50 MiB bộ nhớ so với 329 MiB của Chrome, CPU khoảng một nửa (số liệu chưa kiểm chứng độc lập)
- 🔗 [Nguồn](https://blog.cloudflare.com/kitesurf-open-source/)
