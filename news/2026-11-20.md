### 2. Intern: harness mã nguồn mở chạy model đắt rồi giao việc cho model rẻ, Opus 5.5 + Hy4 Flash đạt 92.4% Terminal-Bench ở $0.127 mỗi tác vụ
- 🔀 Intern chạy mỗi tác vụ trên 3 model: model frontier (Opus 5.5, Fable, Sol…) làm phần khó, model rẻ (Hy4 Flash, DeepSeek Flash, Sonnet hoặc model local) làm nốt, và một "decision model" nhỏ quyết định lúc nào giao việc. Mỗi lượt chạy chỉ giao một chiều, không quay lại
- 📊 Trên Terminal-Bench 2.1 (87 tác vụ), Opus 5.5 giao cho Hy4 Flash đạt 92.4% với $0.127 mỗi tác vụ; Opus 5.5 chạy riêng đạt 91.1–93.7% ở $0.280–0.393 trong Pi, Hermes, OpenCode. Hy4 Flash chạy riêng đạt 82.3–83.5%. Đây là số liệu do nhóm tác giả công bố
- 💰 Hy4 Flash làm khoảng 65% số lần gọi model và 48% output token nhưng chỉ chiếm 1% chi phí
- ⚙️ Cài bằng `uv tool install` (Python 3.12+), khuyên dùng OpenRouter nhưng cũng hỗ trợ Anthropic, OpenAI, Gemini và model chạy máy mình qua Ollama, LM Studio, llama.cpp, vLLM
- 🔗 [Nguồn](https://github.com/nace-ai/intern)

### 3. Vercel Board: "bảng tin" cho agent nhận việc, báo tiến độ và bàn giao PR, v0 software factory đã merge hơn 50% PR nhờ nó
- 📋 Board là primitive thử nghiệm để nhiều agent và người dùng chung một chỗ theo dõi task, phân quyền, trạng thái và log. Hoạt động qua CLI hoặc JavaScript SDK, tổ chức theo channel và thread, agent claim task, đăng cập nhật rồi gửi PR để review
- 🏭 Vercel dùng nội bộ cho swarm agent bảo mật và dựng lại v0 software factory trên Board; theo Vercel, factory này giờ merge hơn 50% số PR
- 🤝 Không phụ thuộc harness: Claude Code, Codex, Pi, OpenCode, Mastra, LangChain đều phối hợp được. Có thể đặt watcher để đánh thức agent khi có reply mới hoặc đổi label, và cho agent tự hẹn lịch kiểm tra CI
- 🧪 Thử bằng `npx skills add vercel/board`. Vercel nói rõ đây là bản thử nghiệm
- 🔗 [Nguồn](https://vercel.com/blog/introducing-vercel-board)
