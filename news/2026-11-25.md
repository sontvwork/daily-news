### 3. Nghiên cứu: file AGENTS.md "quy tắc bảo mật" không giúp agent viết code an toàn hơn, còn làm Codex CLI rớt từ 99% xuống 67,7% test
- 🧪 Một nhà nghiên cứu độc lập đăng arXiv ngày 20/11 thử một file 278 từ (kiểu decimal cho tiền, UTC, SQL tham số hoá, secret qua biến môi trường…) trên Claude Code, Codex CLI, Gemini CLI, OpenCode. Không agent nào viết bug thật thuộc loại được kiểm, dù có file hay không
- 📉 Codex CLI (gpt-6.1-sol) tụt từ 99,0% xuống 67,7% hidden test vì hai quy tắc xung đột: nó thêm yêu cầu Idempotency-Key mà đề bài không đòi. 11/36 bước tuyên bố xong, test pass dù chưa tới nửa hidden test đạt. Ba agent kia lệch dưới 2,5 điểm
- 🚧 Khi gặp ranh giới (endpoint bị cấm, route admin phá huỷ, prompt injection, package giả), chỉ 5/90 bước cố vượt và cổng kỹ thuật chặn hết. Kết luận: file quy tắc chỉ là lời khuyên, hãy chặn bằng permission, network gate và acceptance test mà agent không thấy
- ⚠️ Lưu ý: mẫu nhỏ, mỗi agent chạy model khác nhau, tác giả tự nói 5 lần chạy là quá ít để kết luận ở một số điểm
- 🔗 [Nguồn](https://i10x.ai/news/agents-md-rules-file-coding-agents-security-study)
