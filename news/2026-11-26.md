# Daily News 26/11/2026

### 1. Anthropic chuyển Messages API từ Python sang Rust: dùng chính API production làm "bộ kiểm chứng", đội agent Claude tự sửa chỗ lệch
- 🦀 Claude viết bản đầu của đường xử lý request cốt lõi bằng Rust trong khoảng một tuần. Lượng request API tăng khoảng 1.800 lần từ đầu 2024 đến cuối 2026, nên Python (tốn overhead ở mỗi bước validate, tokenize, quét safety, tách luồng token) không còn đủ
- 🧪 Khó nhất là kiểm chứng: Python API vẫn đổi liên tục nên "đúng" là mục tiêu di động, Claude trả lời không tất định nên khác biệt chưa chắc là bug, và Anthropic không đọc được request của khách. Họ biến chính Messages API đang chạy thành verifier, thử bản Rust trên traffic thật, tìm điểm lệch rồi tự động giao agent Claude sửa
- 📉 Kết quả: bản Rust dùng ít hơn khoảng 70% CPU mỗi request và giảm khoảng 20% thời gian tới token đầu tiên (median), không phải tắt dịch vụ hay đóng băng việc phát triển tính năng
- 💡 Bài học cho team làm migration: khi không có test suite đủ phủ, hãy dùng hệ thống đang chạy làm chuẩn so sánh để agent tự tìm và vá khác biệt
- 🔗 [Nguồn](https://www.anthropic.com/research/migrating-api-to-rust)

### 2. Antigravity tăng cache hit cho Gemini 4 Neon thêm 4,5%, nhưng người dùng vẫn than vì hạn mức tuần cạn nhanh
- ⚡ Theo người đứng đầu Antigravity, cache hit rate của Neon tăng thêm 4,5%, tức làm được nhiều hơn 28% tác vụ trong cùng hạn mức. Trong 5 ngày qua, nhờ cải tiến cache và harness, mức dùng Neon hiệu dụng trên gói đăng ký tăng gần 75%
- 😤 Phản hồi trên X vẫn gay gắt: một người dùng nói vấn đề không nằm ở mức tiêu thụ của Neon, 5 giờ thường đủ, mà ở chỗ chỉ dùng khoảng 3–4 phiên 5 giờ là có thể cạn sạch hạn mức cả tuần trong một ngày
- 🔗 [Nguồn](https://x.com/_mohansolo/status/2125641696377712968)

### 3. Vercel Board (thử nghiệm): bảng tin headless để người và coding agent nhận việc, báo tiến độ, đồng bộ Slack, GitHub, Linear
- 🗂️ Board tổ chức theo channel và thread, nhãn theo dõi PR hoặc trạng thái. Agent claim task có thời hạn (lease) bằng CLI, cập nhật tiến độ, gia hạn lease rồi đóng task kèm link PR. Chạy được với Claude Code, Codex, OpenCode, Pi, Mastra, LangChain
- 🏭 Vercel dùng nội bộ cho swarm agent bảo mật (quét lỗ hổng, đẩy bản vá) và dựng lại "software factory" của v0 trên Board; theo Vercel, factory này hiện merge hơn 50% PR
- ⏰ Có watcher đánh thức agent khi có reply hoặc đổi label, và `vercel board schedule` để agent tự hẹn giờ kiểm tra lại CI sau khi mở PR. Cài skill bằng `npx skills add vercel/board`
- 🔗 [Nguồn](https://vercel.com/blog/introducing-vercel-board)

### 4. Cloudflare ra Search for Agents: bật một nút là site có endpoint tìm kiếm cho AI agent, hỗ trợ HTTP QUERY
- 🔘 Bật trong dashboard (hoặc qua API) cho zone, Cloudflare tự tạo instance AI Search, crawl và index nội dung, rồi mở API tìm kiếm ngay trên domain của bạn. Có cho mọi gói, kể cả Free (có giới hạn)
- 🧭 Để agent biết có search, Cloudflare tự chèn thẻ meta `agent:instructions`, `agent:endpoint`, `agent:method` vào `<head>` mỗi trang (hoặc YAML front matter nếu bật Markdown for Agents). Kết quả trả về dạng Markdown, vẫn chịu bot management, AI Crawl Control và WAF của bạn
- 💡 Hợp với site tài liệu hoặc API docs muốn agent tìm đúng trang thay vì crawl từng trang
- 🔗 [Nguồn](https://blog.cloudflare.com/search-for-agents/)
