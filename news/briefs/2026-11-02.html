Claude Code 2.1.316: chỉnh effort riêng cho subagent, tắt ultrathink, Opus 4.8 fast mode bị khai tử 30/11

  • 🎚️ Thêm biến CLAUDE_CODE_SUBAGENT_EFFORT đặt mức effort cho subagent khi không có chỉ định nào khác, thay vì kế thừa từ session. Thêm CLAUDE_CODE_DISABLE_ULTRATHINK để tắt từ khoá ultrathink
  • ⏳ Fast mode cho Opus 4.8 bị deprecate từ 30/10/2026 và sẽ gỡ ngày 30/11/2026. Sau đó request fast mode trên Opus 4.8 trả lỗi, không tự rơi về Opus 4.8 thường; Anthropic khuyên chuyển sang Opus 5.5 để giữ tốc độ
  • 🏢 Claude apps gateway có thêm ngân sách theo nhóm (pooled_budget: một ngân sách tháng chung cho cả nhóm, ngoài hạn mức từng người) và managed.policy_mode: layered để áp dụng chồng nhiều policy
  • 🐛 Sửa lỗi lệnh shell còn chạy sau khi Claude Code tự thoát trên macOS và Linux, và lỗi PowerShell hook không chặn được khi exit code 2
  • 🛠️ Với dev: nếu pipeline đang bật fast mode Opus 4.8, lên kế hoạch chuyển sang Opus 5.5 trước 30/11; chạy subagent effort thấp để tiết kiệm token

Prospero: coding harness viết bằng C++ với giao diện ImGui, nhẹ hơn các harness khác khoảng hai bậc về tài nguyên

  • 🖥️ Có khả năng điều khiển desktop nếu model hỗ trợ vision
