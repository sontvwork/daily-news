Claude ra mắt message threads: agent chỉ gửi phần mới, Claude Code giảm khoảng 35% thời gian chờ token đầu tiên

  • 🧵 Message threads vào public beta trên Claude Platform. Thay vì gửi lại toàn bộ lịch sử mỗi lượt, agent chỉ gửi tin nhắn mới kèm ID của phản hồi trước; lượt đầu gửi đủ hội thoại để mở thread
  • ⚡ Với Claude Code (đã bật mặc định cho đa số người dùng), request dài 500k–1M token giảm khoảng 35% median TTFT. Theo một bài X, request trong hội thoại dài co từ khoảng 800 KB xuống 1,8 KB
  • 🔒 Thread được giữ mã hoá trong bộ nhớ, không ghi ra đĩa, hết hạn sau 5 phút không có request; khi đó client gửi lại toàn bộ để mở thread mới. Token tiêu thụ không đổi vì Claude vẫn đọc toàn bộ hội thoại, giá và rate limit giữ nguyên
  • 🛠️ Với dev: thêm tham số thread vào Messages API nếu bạn tự viết coding agent hay computer use agent (ảnh chụp màn hình không phải upload lại mỗi lượt). Có trên Claude Platform, AWS, Microsoft Foundry và Google Cloud

Vercel Labs mở mã nguồn agent-desktop: cho coding agent điều khiển ứng dụng desktop qua accessibility tree thay vì đoán toạ độ từ ảnh chụp

  • 🖥️ CLI và thư viện C chạy trên macOS, Windows, Linux. Lệnh snapshot trả JSON kèm một ref cho mỗi phần tử có thể thao tác; agent click theo ref rồi snapshot lại để kiểm tra, không cần so khớp pixel
  • 🫥 Chạy headless mặc định: không giành focus, không tổng hợp input. Cài bằng npm install -g agent-desktop; macOS cần cấp quyền Accessibility, Linux cần at-spi2-core
  • ⚠️ README cảnh báo snapshot, clipboard và ảnh chụp có thể chứa nội dung riêng tư nên đừng đẩy vào log công khai
  • 🛠️ Với dev: hợp để cho agent test app desktop hoặc tự động hoá thao tác GUI mà không tốn token cho ảnh chụp màn hình lớn
