JetBrains Air có sẵn trong mọi IDE 2026.3: chạy Claude Agent, Codex, Junie, Copilot song song, Junie Lite miễn phí

  • 🧰 Air in IDEs là plugin làm "bàn làm việc" cho coding agent, không phải dịch vụ AI riêng. Từ bản 2026.3 plugin được cài sẵn trong các IDE của JetBrains
  • 🔌 Claude Agent, Codex, Junie và Copilot chạy ngay; thêm Gemini CLI, Antigravity, OpenCode, Pi... từ ACP registry hoặc tự nối agent riêng qua ACP. Đăng nhập bằng tài khoản ChatGPT, GitHub Copilot hoặc Google có sẵn, hoặc dùng API key OpenRouter, OpenAI, Anthropic, Gemini
  • 🌿 Chạy nhiều agent song song trong các Git worktree riêng rồi cherry-pick thay đổi về. Agent dùng được tìm symbol, rename refactoring, inspection và run configuration của IDE (kèm debugger trong IntelliJ IDEA và CLion)
  • 🔄 Hết hạn mức giữa chừng thì đổi sang subscription hoặc API key khác ngay trong session. Có thể xem lại lượt cuối và rollback từng file, giao cho agent xử lý merge conflict từ hộp thoại merge
  • 🆓 Junie Lite miễn phí với tài khoản JetBrains

Claude Code 2.1.319: MCP task chạy nền, denyInsteadOfPrompting, và /claude-api latency-optimize

  • ⏳ Khi MCP server chạy tool call dưới dạng task, Claude Code đẩy ngay xuống nền và báo kết quả cho Claude khi xong. Muốn giữ kiểu chờ cũ thì đặt CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND
  • 🚫 Setting mới permissions.denyInsteadOfPrompting: tool call đang chờ hỏi quyền sẽ bị từ chối và lượt chạy tiếp tục, áp dụng cho terminal session, subagent và teammate. Hợp với chạy tự động không có người ngồi duyệt
  • ⚡ /claude-api latency-optimize tìm chỗ code gọi Claude API làm người dùng phải chờ và thử các thiết lập nhanh hơn so với bộ eval của bạn
  • 🗂️ /tasks có mục "Earlier in this session" liệt kê subagent đã xong để mở lại và nhắn tiếp, kể cả sau khi khởi động lại. Có thêm biến CLAUDE_CODE_DISABLE_FEATURE_FLAGS để tắt lấy feature flag mà vẫn giữ telemetry
  • 🏢 Với team dùng Claude apps gateway: /usage hiện chi tiêu theo ngày/tuần/tháng, thêm admin.pooled_priority_order để chọn ngân sách nhóm nào trả trước

OpenAI tổng kết Agents API tháng 10: auto review, automations, đổi tool giữa session, compaction chạy nền

  • 🛡️ auto_review: một model tự duyệt hoặc từ chối các yêu cầu tool và quyền được hỗ trợ dựa trên ý định hội thoại và mức rủi ro, tương tự "review for me" của Codex. Có tính thêm token
  • ⏰ Automations: hẹn việc một lần hoặc lặp lại trong session mới hay cũ, agent cũng tự đặt lịch follow-up được, kiểu "kiểm tra X mỗi giờ"
  • 🔧 Cập nhật danh sách tool khi session đang chạy: function tool và MCP server đổi ở lần gọi model kế tiếp, tool built-in đổi trước lượt sau. Compaction giờ chạy nền theo mặc định (có thể tăng lượng token dùng)
  • 🏎️ Cũng có sandbox prewarming, sandbox snapshot khôi phục môi trường sau khi idle còn nguyên file, prompt caching 12 giờ và cache system prompt xuyên session. Đang làm beta: memory, budget control (giới hạn ngân sách đô la cho agent)
