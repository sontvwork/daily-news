Anthropic ra Claude Fable 5.2 và Mythos 5.2: nhanh hơn 30%, giá giảm còn $8/$40, Claude Code đã lấy làm Fable mặc định

  • 💰 Giá $8 / $40 mỗi triệu token input/output (Fable 5.1 là $10 / $50), tốc độ sinh output nhanh hơn tới 30%. Có fast mode tăng tốc tới 2,5 lần với giá $16 / $80. Fable và Mythos là cùng một model nền; Fable có safeguards an ninh mạng/sinh học nên mở cho mọi gói trả phí, còn Mythos phải đăng ký chương trình xác minh
  • 📊 FrontierSWE v2 đạt 69,9% (Opus 5.5: 62,3%, GPT-6 Astra: 65,5%, Gemini 4 Carbon: 61,2%); FrontierCode 2.0 đạt 49,1% ở mức xhigh effort (Opus 5.5: 45,5%)
  • 🧪 Anthropic kể một nhóm 1.000 agent Fable 5.2 chứng minh hình thức hoá định lý Fermat cuối cùng trong 30 giờ, so với 11 ngày của bản nghiên cứu trước. Họ cũng nói model giúp kỹ sư hoàn tất các đợt migration phần mềm vốn "bất khả thi"
  • 🖥️ Claude Code v2.1.321 đã thêm claude-fable-5-2 làm Fable mặc định: context 1M, cache read $0,20/Mtok. Bản này còn có --settings <file> cho claude remote-control và nhiều bản sửa lỗi sandbox/permission
  • 💬 Trên Hacker News, một người dùng thử nói với code thường ngày khó phân biệt Fable 5.2 với Opus 5.5, chỉ thấy khác biệt khi prompt thật tham vọng. Chính Anthropic khuyên bắt đầu với Opus 5.5, lên Fable/Mythos khi việc lớn hơn; Fable cũng có thể làm Advisor hoặc Orchestrator cho model nhỏ

"Agent memory cần khoảnh khắc OpenTelemetry": mỗi tool lưu memory một kiểu, chưa tool nào đọc được của nhau

  • 🗃️ Bài của tác giả LoreKit đếm các định dạng memory trên một máy dev điển hình: AGENTS.md/CLAUDE.md, .cursor/rules/*.mdc, thư mục /memories của memory tool Anthropic, memory của Copilot lưu phía GitHub, và memory MCP server dạng JSONL knowledge graph. Bốn kiểu, không kiểu nào đọc được kiểu nào
  • 🔄 Bài so sánh với OpenTelemetry, nơi OpenTracing và OpenCensus sáp nhập năm 2019 để các vendor thống nhất data model và semantic conventions thay vì tự làm agent riêng. Tác giả nói rõ format của LoreKit chỉ là một đề xuất trong số nhiều, còn thiếu sót
  • 💬 Trên Hacker News bài thu hút 108 bình luận, phản ánh vấn đề lock-in giữa các harness mà nhiều dev đang gặp khi đổi công cụ
