Google Antigravity thêm Dynamic Workflows: agent tự viết script Python điều phối subagent, luồng chạy cố định thay vì "trôi" theo prompt

  • 🧭 Gõ /run-workflow, agent sẽ viết một script Python để điều phối các subagent chạy song song hoặc tuần tự, với cơ chế bàn giao kết quả có cấu trúc giữa các bước

  • 🔍 Script được hiển thị để bạn review trước khi chạy, và có thể lưu lại để chạy lại đúng quy trình đó bất cứ lúc nào

Brave Search API nhận thanh toán cho agent qua giao thức x402: không cần tài khoản hay API key, $5 cho 1.000 lượt

  • 💳 Agent gọi API, nhận về HTTP 402 Payment Required kèm giá và thông tin thanh toán, ký giao dịch USDC rồi gửi lại request kèm bằng chứng thanh toán. Brave tự vận hành facilitator, hiện nhận USDC trên mạng Base, các mạng và stablecoin khác sẽ có sau
  • 💰 LLM Context (API cấp context tìm kiếm cho agent) và các endpoint web, news, image, video, local đều $0,005 mỗi request ($5 cho 1.000). Phí gas trên Base được Brave trả trong thời gian giới hạn
  • 🛠️ Cách bắt đầu nhanh nhất: dùng Purl Wallet, ví CLI do Stripe phát triển, nạp USDC trên Base rồi cho agent truy vấn
