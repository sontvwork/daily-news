Cursor công bố chi tiết vụ lộ key qua Fireworks: bản Claude Code giả nằm trên marketplace khoảng 11 tiếng

  • 🔑 Kẻ tấn công lấy được một access key Cursor cấp cho Fireworks (do phía Fireworks để lộ), dùng nó sao chép dữ liệu từ bucket chỉ đọc chứa các trace coding agent, chủ yếu từ 2025, của những phiên không bật Privacy Mode. Một số trace còn chứa credential chưa được che; dưới 0,01% khách hàng bị lộ API credential
  • 🧨 Từ đó kẻ tấn công vào một số công cụ SaaS của Cursor, rồi ngày 29/10 đặt bản sao độc hại của extension Claude Code lên cache phục vụ marketplace extension của Cursor. Tối đa 5.000 người tải đúng các phiên bản cache hôm đó có thể dính, bản độc tồn tại khoảng 11 tiếng. Anthropic không phát hành bản này, Open VSX cũng chưa từng chứa mã độc
  • 🛠️ Nếu bạn cài hoặc cập nhật Anthropic.claude-code 2.1.312 hoặc 2.1.313 từ marketplace của Cursor trong khung giờ đó, làm theo hướng dẫn trong thông báo bảo mật của Cursor
  • 🧹 Bài học cho team: log/trace của agent dễ chứa key chưa che và hay bị chia sẻ cho bên thứ ba. Nên rà xem trace đang đưa cho ai, và có bước lọc secret trước khi chia sẻ hay không

Cloudflare mở mã nguồn Kitesurf, trình duyệt cho AI agent chạy hoàn toàn trên Workers

  • 🌐 Kitesurf mở trên GitHub theo giấy phép Apache 2.0. Nó phân tích HTML, áp CSS, chạy JavaScript của trang và render ảnh chụp màn hình mà không cần container trình duyệt, scale theo nhu cầu trên mạng Workers
  • 🔌 Hỗ trợ Chrome DevTools Protocol nên nối thẳng với Puppeteer hoặc cho agent trỏ vào cổng CDP. Xây trên các package Rust biên dịch sang WebAssembly: Blitz (HTML/DOM/layout), Stylo (CSS), Boa (JavaScript, chỉ là phương án cuối)
  • 🛠️ Chạy thử local: git clone, pnpm install --frozen-lockfile, pnpm run dev (lần build đầu biên dịch Rust nên khá lâu). Muốn tự triển khai lên tài khoản Cloudflare thì dùng pnpm run deploy, cần gói Workers Paid vì dùng Dynamic Workers
  • 📉 Một bài đăng X trích số liệu: mỗi ảnh chụp dùng khoảng 50 MiB bộ nhớ so với 329 MiB của Chrome, CPU khoảng một nửa (số liệu chưa kiểm chứng độc lập)
