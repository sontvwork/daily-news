GitHub Copilot app thêm security extension: hỏi Copilot để tìm, giải thích và sửa cảnh báo code scanning

  • 🔒 Extension đang public preview, cho phép xem các cảnh báo code scanning (xếp theo mức nghiêm trọng) ngay trong Copilot app, bấm Explain để Copilot giải thích lỗ hổng hoặc Fix để nó sửa code, có thể chọn nhiều cảnh báo một lúc
  • 🔍 Còn chạy được "local security review" để soi thay đổi cục bộ tìm lỗ hổng mới trước khi mở pull request, và việc này không cần bật code scanning hay mua GitHub Code Security
  • 🛠️ Cài bằng copilot plugin install github-security@awesome-copilot hoặc tìm github-security trong mục Customize của app. Áp dụng cho mọi gói Copilot
  • ⚠️ Giới hạn: chỉ hiện cảnh báo code scanning (không có Dependabot hay secret scanning), chưa hỗ trợ GitHub Enterprise Server, repo private cần GitHub Code Security. Sau khi Fix vẫn nên review diff và chạy test

"Mọi code do AI sinh ra nên là Open Source": bài viết lên hơn 1.000 điểm Hacker News, cộng đồng phản biện mạnh

  • 📝 Tác giả Jakub Jankiewicz lập luận hai điểm: model được huấn luyện trên kho code open source (và Stack Overflow, vốn dưới giấy phép Creative Commons yêu cầu ghi nguồn) nên biến nó thành code đóng là "license laundering"; code thuần AI cũng không do con người viết nên không nên có bản quyền. Ông đề nghị công bố dưới giấy phép mở hoặc CC0
  • ⚖️ Phía phản bác trên Hacker News dẫn hướng dẫn của US Copyright Office: dùng AI để hỗ trợ chứ không thay thế sáng tạo của con người thì không ảnh hưởng quyền bản quyền của sản phẩm. Vụ Doe v. GitHub cũng được nhắc là chưa coi output LLM tự động là open source
  • 🧑‍💻 Nhiều dev cho rằng AI chỉ là công cụ như compiler, phần định hướng và kỹ thuật của người dùng vẫn đáng kể. Một tác giả dự án AGPL kể có công ty dùng LLM "nhân bản" hệ thống của mình để né điều khoản giấy phép
  • 💡 Với team: nên xác định rõ chính sách giấy phép và mức độ con người can thiệp với code AI sinh ra, nhất là khi phát hành dưới dạng sản phẩm thương mại
