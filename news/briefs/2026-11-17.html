Alibaba ra mắt Qwen4-Max: 2.4T tham số, 1M context, rẻ hơn Qwen3.8-Max khoảng 60% mỗi tác vụ

  • 🧠 Kiến trúc MoE mới với 2.4 nghìn tỷ tham số, chỉ kích hoạt 71 tỷ mỗi token (ít hơn 25% so với Qwen3.8-Max), có native vision và context 1 triệu token
  • 📊 Hạng 6 trên Code Arena (bảng xếp hạng coding thực tế). Trên benchmark nội bộ Work360, model dùng ít hơn 35% token ở chế độ High effort và giảm chi phí mỗi tác vụ khoảng 60% so với bản tiền nhiệm
  • 💲 Đã có trên QwenCloud qua Token Plan và API; giá input khi trúng cache là $0.075 / 1M token. Alibaba cho biết các model Qwen4 open-weight nhỏ hơn sẽ ra sau
  • 🛠️ Với dev: đáng thử làm lựa chọn rẻ cho agent coding chạy khối lượng lớn. Các con số phần lớn là benchmark nội bộ của Alibaba nên cần tự đo trên codebase của mình

Windows 11 bị phát hiện ghi nhận bạn dùng coding agent nào: có cả claude.exe, codex.exe, cursor.exe

  • 🔍 Một dev dùng AI hỗ trợ dịch ngược thành phần MissionControlAggregator.dll và thấy nó so khớp tên các CLI agent (copilot, claude, codex, agy) và desktop agent (github, claude, codex, cursor, antigravity), cùng công cụ như python, node, dotnet, gcc, code
  • 📡 Dữ liệu lấy từ các sự kiện Windows sẵn có (kể cả WSL), lưu cục bộ và báo vào Windows Diagnostics. Tính năng tên CLICodingAgentUsage. Nếu bạn chưa tắt diagnostic data "optional" (bật mặc định) thì dữ liệu được gửi lên Microsoft
  • 🛡️ Với dev: nếu quan tâm riêng tư, kiểm tra lại cài đặt diagnostic data trên máy Windows. Đây là kết quả reverse-engineering của một cá nhân, Microsoft chưa có phản hồi trong bài
