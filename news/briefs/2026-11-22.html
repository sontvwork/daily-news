MomongaCode v0.1.0: coding agent terminal mã nguồn mở, bộ nhớ có bằng chứng và tiết kiệm token mặc định

  • 🧠 Bộ nhớ do runtime dựng từ các sự kiện đã ghi, không để model tự quyết. Mỗi memory có loại (fact, episode, procedure), phạm vi (user hoặc project) và vòng đời. Memory gắn với file kèm hash SHA-256 sẽ bị đánh dấu cũ khi file đổi

  • 💸 Tiết kiệm token bật sẵn, kèm lệnh eval để đo từng khoản tiết kiệm so với baseline khi tắt tính năng
  • 🔒 Chạy được với model local lẫn hosted, mỗi tool call chạy dưới hệ thống permission và OS sandbox. Cài bằng một dòng curl (macOS/Linux) hoặc PowerShell (Windows), lệnh là momonga. Giấy phép MIT
