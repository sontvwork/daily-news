Claude Code làm lộ secrets qua tính năng "Don't Ask Again": Apiiro tìm thấy 63 tổ chức bị ảnh hưởng

  • 🔓 Khi bạn chọn "Yes, and don't ask again" cho một lệnh shell, Claude Code lưu lệnh đó thành rule vĩnh viễn trong .claude/settings.local.json. Nếu lệnh có sẵn mật khẩu hay token thì chúng nằm luôn trong file này
  • 📊 Apiiro tìm thấy 1.122 secrets trong các file settings.local.json và 1.160 secrets khác trong git history, settings.json được commit và transcript chat của agent. Có 63 tổ chức bị ảnh hưởng, gồm cloud API key, mật khẩu production và npm token. Gitleaks và TruffleHog bỏ sót nhiều vì secret nằm trong chuỗi lệnh shell
  • 🧪 GitGuardian xác nhận độc lập: 31.088 secrets trong file này trên GitHub public, 5.343 cái còn hiệu lực lúc phát hiện
  • ⚠️ Claude Code chỉ thêm file vào global gitignore. Thư mục thành repo sau này, clone sang máy khác hay file đã commit từ trước thì không được che, và có trường hợp chính Claude Code commit file này
  • 🛠️ Làm ngay: git rm --cached .claude/settings.local.json, thêm vào .gitignore của repo, xoá rule chứa secret và đổi mọi credential đã từng nằm trong đó. Về lâu dài, đừng gõ secret thẳng vào lệnh, hãy dùng biến môi trường

  • 💬 Trên Hacker News, một người kể nhận email báo rằng MiniMax đọc prompt, phát hiện nhờ URL mồi gắn trong request. Một người khác nói ZDR tốt nhất là thỏa thuận trực tiếp với nhà cung cấp, nhưng không phải team nào cũng đủ quy mô để có

GitHub Agentic Workflows: viết automation cho repo bằng Markdown, coding agent chạy trong GitHub Actions

  • 📝 Mỗi workflow là một file Markdown gồm frontmatter YAML (trigger, quyền, "safe outputs" được phép ghi) và phần thân là chỉ dẫn bằng ngôn ngữ tự nhiên. Biên dịch ra file .lock.yml rồi commit như workflow Actions bình thường
  • 🤖 Ví dụ trong tài liệu: triage issue và gắn nhãn theo loại, mức ưu tiên; điều tra CI lỗi và đề xuất sửa; báo cáo trạng thái repo hằng ngày; cập nhật tài liệu theo code; tăng test coverage
  • 🔐 Agent chạy trong container có firewall với token chỉ đọc theo mặc định, mọi thao tác ghi bị giới hạn ở safe outputs đã khai báo và qua kiểm tra threat detection. Kết quả là issue, comment hay PR để người duyệt, quyền merge vẫn ở bạn
  • 🧩 Hỗ trợ nhiều agent: GitHub Copilot, Anthropic Claude, OpenAI Codex, Google Gemini. Cần bật GitHub Actions và cài GitHub CLI
