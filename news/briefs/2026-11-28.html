Pydantic ra mắt Pax: coding agent trên terminal mà "mọi thứ đều là plugin", tự mang agent của mình bằng --agent

  • 🧩 Pax (pydantic-ai-pax) là coding agent chính thức của Pydantic AI, xây trên Harness SDK. Ngay cả coding agent cũng là một plugin; /plugins disable coder biến nó thành client chat thuần không có tool file/shell. Còn có plugin sandbox, MCP, tracing Logfire
  • 🔌 pax --agent cho phép thay agent mặc định bằng bất kỳ Pydantic AI Agent nào trong codebase, rồi ship cùng Agent đó vào service của bạn. Cài nhanh bằng uvx pydantic-ai-pax
  • 📊 Trong các lượt chạy Harness-Bench SWE81, Pax có điểm trung bình cao nhất (sát nút) trong 4 harness chạy đủ 8 model. Chi phí chưa bằng một nửa Codex trên GPT-6.2 Sol, và xấp xỉ Claude Code trên Claude Opus 5.5
  • 🛠️ Pydantic AI Harness có hơn 100 capability và dự kiến lên 1.0 sau khoảng một tháng; hãng kêu gọi thử nghiệm ngay để góp ý trước khi API được chốt
